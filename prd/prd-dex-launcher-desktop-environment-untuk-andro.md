# PRD: DEX — Launcher Desktop Environment untuk Android (Layar 4.9"+, Rasio Apa Pun, Dioptimalkan Penuh)## RingkasanDEX (Desktop Environment for Android eXperience)adalah **launcher** Android open-source yang mengubah perangkat Android menjadi desktop sungguhan. Pengguna membuka aplikasi dalam bentukjendela (window)yang bisa digerakkan, di-resize, diminimalkan, dimaksimalkan, dan ditumpuk, lengkap dengan taskbar, wallpaper, dan ikon desktop yang meniru perilaku Windows/macOS/Linux. DEX dioptimalkan untuk **semua perangkat dengan layar di atas4.9inci pada rasio layar apa pun**, dengan tampilan yang **otomatis menyesuaikan** terhadap ukuran dan rasio layar serta **smooth** saat interaksi maupun rotasi. DEX memakai **landscape sebagai tata letak utama** dengan **potret didukung penuh**, dapat diaktifkan sebagai launcher default **secara opsional**, menyimpan state desktop **lokal** dengan **ekspor/impor** untuk cadangan & pindah perangkat, bersifat **open source penuh (gratis)dengan lisensi **Apache2.0**, dan dipublikasikan di GitHub agar bisa di-build sendiri.## Asumsi1. DEX adalah **launcher Android** (bukan virtual machine / emulator) aplikasi yang "dibuka" adalah aplikasi Android biasa yang dirender dalam jendela.2. Pengaturan sebagai launcher default bersifat **opsional** pengguna memilih sendiri, tanpa paksaan.3. Target perangkat: **semua layar atas4.9inci dengan rasio apa pun** ponsel besar4.9"), tablet kecil/besar, foldable, dan rasio tidak umum (ultrawide/sempit). Layar4.9inci tidak didukung.
4. **Tampilan otomatis menyesuaikan** terhadap ukuran **dan rasio** layar; tidak ada asumsi rasio tetap. Landscape tetap tata letak utama, potret didukung penuh.
5. Dukungan multi-window/resize memanfaatkan Android **Freeform Window Mode** (stabil sejak Android8.0/API 26+).
6. "Aplikasi dibuka" mencakup aplikasibawaanDEXsendiri (Notepad, File Manager, Kalkulator, Browser)**dan** aplikasi Android pihak ketiga yang di-install pengguna.
7. **State desktop disimpan lokal** perangkat, tanpa akun/server/cloud. Perpindahan antar perangkat dilakukan lewat **ekspor/impor** manual.
8. Aplikasi **gratis penuh** tanpa paywall, iklan, atau fitur berbayar; keberlanjutan proyek lewat donasi/sponsor opsional.
9. Proyek **open source** dengan lisensi **Apache2.0**; seluruh kode dipublikasikan GitHub dan bisa di-build oleh siapa pun.## Latar Belakang & MasalahAndroid dirancang sebagai sistem operasi mobile: satu aplikasi layar penuh, navigasi gesture, dan tanpa konsep jendela bertumpuk. perangkatberlayarbesar (tablet, ponsel besar, foldable)keterbatasan ini terasa jelas pengguna tidak bisa membuka banyak aplikasi sekaligus dengan bebas, tidak bisa memposisikan jendela, dan harus terus-menerus berpindah lewat app switcher yang memecah fokus. Pengguna yang terbiasadengandesktop (pelajar, pekerja kantoran, developer)kehilangan produktivitas karena metafora "desktop" tidak tersedia. Banyak solusi desktop hanya mengoptimalkan satu faktor bentuk atau rasio layar tertentu, sehingga tampilannya rusak atau kaku perangkat lain, apalagi saat diputar. DEX menjawab masalah ini dengan menghadirkan launcher desktop: jendela bisa di-resize, taskbar, dan ruang kerja persisten **yang otomatis menyesuaikan terhadap ukuran dan rasio layar apa pun** serta **halus saat diputar**, sehingga perangkat Android mana pun bisa dipakai layaknya desktop sungguhan. Karena open source dan gratis, siapa pun bisa membangun, mengubah, dan berkontribusi sendiri lewat GitHub.## Tujuan (Goals) dan Bukan Tujuan (Non-Goals)### Tujuan**G1.** Menyediakan **launcher** desktop dengan ikon, wallpaper, dan taskbar yang dapat dikustomisasi, serta **dapat** (opsional) diaktifkan sebagai launcher default.
**G2.** Memungkinkan setiap aplikasi dibuka dalam **jendela freeform** yang bisa digerakkan dan di-resize bebas.
**G3.** Mendukung multi-jendela bersamaan:tumpuk (z-order)minimize, maximize, dan restore.
**G4.** Menyediakan aplikasibawaanringan (File Manager, Notepad, Kalkulator, Browser)yang dioptimalkan untuk mode jendela.
**G5.**Smooth (halus)**: animasi dan interaksi jendela berjalan mulus minimal 45–60 FPS tanpa lag, termasuk saat rotasi.
**G6.** **Optimal semua layar4.9inci dengan rasio apa pun** (ponsel besar, tablet kecil/besar, foldable, ultrawide/sempit)bukan hanya satu faktor bentuk.
**G7.** **Tampilan otomatis menyesuaikan** ukuran dan rasio layar, dansaatrotasi (landscape ↔ potret)tanpa jendela keluar layar.
**G8.** Menyimpan state desktop **secara lokal** agar pulih setelah aplikasi ditutup atau perangkat dimulai ulang, tanpa internet.
**G9.** Menyediakan **ekspor impor state desktop** (file backup)DEX untuk cadangan dan pindah perangkat secara manual.
**G10.** **Open source gratis penuh**: seluruh kode dipublikasikan GitHub (Apache2.0agar bisa di-build, di-fork, dan dikembangkan komunitas.### Bukan Tujuan**NG1.** **Bukan**penggantiAndroid (bukan OS virtual / virtual machine).
**NG2.** **Bukan** emulator untuk menjalankan aplikasi Windows/Linux desktop.
**NG3.** **Tidak** mendukung perangkat dengan layar4.9inci pada rilisawal.
**NG4.** Versi awal tidak menyediakan ekosistem widget/plugin pihak ketiga.
**NG5.** **Bukan** aplikasi cloud tidak ada akun, server, atau sinkronisasi otomatis antar perangkat; semua data tersimpan lokal dan berpindah perangkat hanya lewat ekspor/impor manual.
**NG6.** Tidak ada fitur berbayar, langganan, atau iklan **gratis penuh**.
**NG7.** Tidak ada dukungan multi-pengguna/akun (multi-profile)pada versi awal.
**NG8.** Landscape tetap tata letak utama, tetapi potret didukung penuh dengan penyesuaian otomatis bukan "layout bekas".## Target Pengguna / Persona| Persona | Deskripsi | Kebutuhan utama ||---|---|---|| **Rina, Pelajar** (17 th) | Punya tablet untuk catatan & tugas sekolah | Buka dokumen + browser bersamaan, jendela bisa disusun, rapi saat diputar || **Budi, Pekerja kantoran** (32 th) | Memakai tablet/ponsel besar Android untuk kerja ringan | Multi-window produktif, taskbar cepat, launcher default opsional || **Dimas, Developer/Prosumer** (28 th) | Power user, ingin build sendiri dari GitHub | Open source, customisasi, performa smooth, ekspor/impor state || **Sari, Freelancer kreatif** (27 th) | Pakai ponsel besar/foldable untuk desain & komunikasi | Layout adaptif saat membuka/lipat layar, file manager yang baik |## User StoriesSebagai pengguna, saya ingin membuka aplikasi dalam jendela, supaya saya bisa melihat beberapa aplikasi sekaligus layar yang sama. beberapa memaksa fullscreen atau crash saat di-resize. Mitigasi: mode kompatibilitas dan daftarpengecualian (allowlist/denylist). **Ragam perangkat yang luas:** Menargetkan semua layar4.9inci dengan rasio apa pun berarti pengujian banyak kombinasi ukuran, kerapatanpiksel (dp/dpi), dan faktorbentuk biaya dan waktu meningkat. Mitigasi: emulator beragam ukuran/rasio dan uji nyata pada minimal 5–7 perangkat berbeda. **Kompatibilitas OEM:** Implementasi freeform dan perilaku rotasi berbedaantarvendor sehingga perilaku resize bisa tidak konsisten. Perlu pengujian nyata sebelum rilis. **Performa pada perangkat rendah:** Menjalankan beberapa aplikasi sekaligus menekan RAM dan baterai. Mitigasi: batasi jendela aktif, jeda otomatis aplikasi background, opsi "mode hemat daya", dan profil rendering ringan.### Keputusan Teknis (Pertanyaan yang telah ditetapkan)
